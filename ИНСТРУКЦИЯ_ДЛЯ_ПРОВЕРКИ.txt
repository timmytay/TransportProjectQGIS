
=====================================================================
1. ЗАПУСК
=====================================================================
Нужно: Windows:
  - обычный Python 3.10 
1) Распакуйте архив в любую папку (например на рабочий стол).
2) Дважды щёлкните run_server.bat. Он сам найдёт Python и при первом запуске сам установит
   недостающие библиотеки (нужен интернет, 1–3 минуты). Откроется чёрное окно — не закрывайте его.
3) Через 1–2 минуты откройте в браузере:  http://127.0.0.1:8000
   (если страница не открылась — подождите ещё минуту и нажмите F5).
4) Журнал сервера пишется в файл server.log в этой же папке.

Если в server.log ошибка «No module named ...»: в командной строке в папке проекта выполните
   python -m pip install -r requirements.txt
и снова запустите run_server.bat.

Первое районирование по центроидам занимает дольше обычного (1–3 мин): сервер один раз
строит файл центроидов и загружает граф дорог. Дальше — секунды.
